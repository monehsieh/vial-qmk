# Mone's Vial-QMK Custom Firmware Repository

## Github repo

https://github.com/monehsieh/vial-qmk#

This github repo is shared between mone-ploopy and monenumpad


##  Active Branch

### monenumpad

custom firmware for my DIY numpad project.
It based on a much older version of vial-qmk (from 2022).
The source for monenumpad is in https://github.com/monehsieh/mone_numpad

### mone-ploopy

It is based on a recent vial-qmk.
It only contains a minor changes from the original ploopy source.


## Build Instruction for mone-ploopy

```bash
qmk compile -kb ploopyco/madromys -km default
```
